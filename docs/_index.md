# Liminal docs

Liminal is a coding agent built on Effect. A small kernel hosts plugins, and everything else, including the built-in features, is a plugin that another plugin with the same contract can replace.

## Start here

1. [status.md](status.md): what is being worked on, what comes next, and the open topics.
2. [requirements/](requirements/_index.md): what Liminal must be, one file per core topic.
3. [plugins/](plugins/_index.md): every planned plugin, with a file for each plugin that has requirements of its own.
4. [plans/](plans/_index.md): work being planned or built.

## Folders

| Folder | Holds |
| --- | --- |
| `requirements/` | Agreed requirements, one terse bullet each, in numbered topic files |
| `plugins/` | The plugin catalog and one file per plugin with real content |
| `plans/` | One file per piece of work in progress; moved to `plans/archive/` once built and verified |
| `instructions/` | Rules for agents, indexed by the table in `AGENTS.md` |
| `reference/` | Version-matched dependency docs, generated by `mise run docs` |
