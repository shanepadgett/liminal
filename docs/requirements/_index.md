# Requirements

What Liminal must be, one file per core topic. Each file opens with a purpose line, lists requirements as terse bullets, and ends with an `Open` section only when something is unsettled. Requirements for a single plugin live in its file under [plugins/](../plugins/_index.md).

| File | Covers |
| --- | --- |
| [01-goals.md](01-goals.md) | Frontends and deployment modes, in order |
| [02-architecture.md](02-architecture.md) | Kernel, protocol, reload |
| [03-plugin-model.md](03-plugin-model.md) | Plugin shape, loading, orchestration |
| [04-sessions.md](04-sessions.md) | Session nouns, the log, durability, workspaces |
| [05-frontends.md](05-frontends.md) | Frontends as plugin hosts, UI slots, keys |
| [06-tui-design.md](06-tui-design.md) | Look and feel of the TUI and the transcript |
| [07-repository.md](07-repository.md) | Workspace layout, guardrails, testing |
