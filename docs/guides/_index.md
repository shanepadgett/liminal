# Guides

How to build on Liminal. Every feature is a plugin, so each guide covers one job a plugin author does.

| Guide | Read when you are |
| --- | --- |
| [plugins.md](plugins.md) | Writing a plugin's server part: its manifest, contract, entries, tools, hooks, prompt sections, settings or storage |
| [tui.md](tui.md) | Writing a plugin's TUI part: transcript views, commands, dialogs, keys and colors |
| [providers.md](providers.md) | Adding a model provider: its stream, model list, API key or sign-in |
| [packaging.md](packaging.md) | Shipping plugins outside the repository: the annex's layout, plugin folders, `plugins.json` and reloads |
| [testing.md](testing.md) | Testing a plugin's server, provider or TUI part |
