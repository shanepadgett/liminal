# Liminal

**The most elegant coding agent.**

Coding agents have become noisy: too many modes, too many knobs, too much ceremony. Liminal is built on the opposite idea. You describe the change, and it makes the change. The interface stays small, the defaults are sensible, and the code it writes reads like you wrote it.

> Status: early development. Nothing is released yet.

## Principles

- **Simple by default.** One obvious way to do each thing.
- **Quiet.** It shows what matters and nothing else.
- **Respectful of your code.** Small, reviewable diffs that follow your conventions.
- **Fast.** Built on Bun and TypeScript.

## Getting started

```bash
mise run setup
```
