# @shanepadgett/liminal-theme

Liminal's colors, shared by every frontend. Its contract holds the color names components use:

| Type | What it is |
| --- | --- |
| `RoleName` | What a color is for, such as `text.muted` or `fill.danger` |
| `Palette` | A near-colorless base, one accent and the status hues, as OKLCH ramps |

The plugin provides no services yet.
