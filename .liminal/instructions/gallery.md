# Gallery

- Treat `apps/gallery` as a sketchpad for trying designs. Change it freely; no product code depends on it.
- Never import product packages into the gallery, or gallery code into the product.
- Copy a design the product takes into the product's own code. Later gallery changes do not flow to the copy.
