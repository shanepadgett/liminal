# Liminal

Liminal is a clean-room reimplementation and reimagining of `tau-agent`, focused on a better architecture rather than carrying forward its existing structure. Use references to learn from their designs and tradeoffs; implement Liminal independently.

- Before building a plugin, TUI part, model provider or test, read the guide for that job in `docs/guides/` (start at `docs/guides/_index.md`).
- Never answer from memory alone when the answer is a matter of judgment or can change over time: APIs, versions, best practices, tool behavior, recommendations. Ground it in the codebase, `docs/reference/`, the reference repositories or a web search, and say which.
- Reference repositories are read-only. Do not modify them or copy their implementation into Liminal.
